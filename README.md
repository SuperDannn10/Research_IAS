# student directory & payment management system

react + typescript + vite admin web app for organizing student information and school payment records.

## purpose
sdpms keeps student profiles, png/jpg profile pictures, payment information, discounts, payment history, and promissory-note requests in one interface.

## run
```bash
npm install
npm run dev
```

## workflow
login → hamburger sidebar → dashboard/student directory/payment information/payment records/settings/about. student profile pictures can be selected per added student. payment discounts range from 10% to 100%, and promissory-note requests identify the selected student.
